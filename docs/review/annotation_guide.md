# E2 결과 검토 판정 가이드 (guide_version 1.0, 2026-09-29)

이 가이드는 **E2 관련성 판정 결과를 검토하기 위한 보조 판정 기준**이다. 여기서 나온 판정은 정답 라벨이나 학습 라벨이 아니다.
검토 결과는 연구자가 근거를 확인하고 결정 기록을 남긴 뒤에만 코드·설정 변경의 근거로 쓴다.

## 1. 판단 대상

판단 대상은 "주가를 언급했는가"가 아니라 **"콘텐츠산업에 관한 실질적인 정보를 제공하는가"**다.
콘텐츠 관련성과 시장 중심 여부를 **각각** 기록한다. 한쪽을 먼저 지우지 않는다.

콘텐츠산업 범위: 게임, 음악, 방송 및 영상, 만화(웹툰·웹소설 포함), 애니메이션, 캐릭터.

## 2. 기록 필드

| 필드 | 값 | 의미 |
|---|---|---|
| content_relevance | SUBSTANTIVE / INCIDENTAL / NONE / UNCERTAIN | 실질적 산업 정보 / 단순 언급 / 관련 정보 없음 / 자료 부족 |
| market_focus | YES / NO / UNCERTAIN | 시세·증권 평가가 기사의 중심인지 |
| review_class | CONTENT / MARKET / OTHER / UNRESOLVED | 비교를 위한 보조 판정 (학습 정답 아님) |
| content_evidence | 입력 제목·요약에 실제로 있는 짧은 문구 | 관련성 판단 근거 |
| exclusion_evidence | 입력에 실제로 있는 짧은 문구 또는 빈 값 | 시장·일반 정치·타 업종 등 제외 의견 근거 |
| reason_short | 한 문장 | 판정 이유 |
| needs_more_context | YES / NO | 제목·요약만으로 부족하면 YES |

**실질적 콘텐츠 산업 정보**: 작품(게임·드라마·영화·음반·웹툰·캐릭터 등)의 제작·출시·유통·편성·공연,
이용·시청·흥행 성과와 반응, 콘텐츠 기업의 사업 전략·실적·제작 투자·인수합병·유통 계약·IP 활용,
콘텐츠 대상 정책·규제·지원사업·저작권·방송 제도.
금액이나 '투자'라는 표현이 있다는 이유만으로 제외하지 않는다.

## 3. review_class 정리 순서

1. 실질적인 콘텐츠 산업 정보(content_relevance = SUBSTANTIVE)가 확인되면 **CONTENT**. market_focus가 YES여도 가능하다.
2. 콘텐츠 정보가 단순 언급(INCIDENTAL)이거나 없고(NONE), 시세·증권 평가가 중심이면 **MARKET**.
3. 콘텐츠 정보가 단순 언급이거나 없고, 일반 정치·사회·타 업종이 중심이면 **OTHER**.
4. 제목·요약만으로 판단하기 어려우면 **UNRESOLVED**. 정보 부족은 기사 분야와 별개의 상태다. 추측으로 보완하지 않는다.

## 4. 혼합·경계 사례 (판정 가이드용 예시이며 실제 기사 판정 결과가 아님)

| 사례 유형 | 보조 판정 | 검토 이유 |
|---|---|---|
| 작품의 실제 시청 성과·반응 변화를 설명하며 주가 하락을 보도 | CONTENT, market_focus 별도 표시 | 작품 성과 정보가 있음 |
| 신작 출시일·해외 계약 내용을 설명하며 기업 주가 상승을 보도 | CONTENT, market_focus 별도 표시 | 출시·유통 정보가 있음 |
| 작품명을 언급하며 '흥행 기대감에 강세'만 보도하고 추가 정보 없음 | MARKET | 구체적 산업 정보 없이 시세 설명에 그침 |
| 콘텐츠 지원 예산·방송산업 제도·저작권 정책을 다룬 정치 기사 | CONTENT | 정치 섹션이어도 정책 대상이 콘텐츠 산업임 |
| 방송사 라디오 인터뷰에서 일반 정치인의 발언을 전달 | OTHER | 방송사가 기사의 출처로만 등장 |
| 제목·요약이 잘려 실질적 내용을 확인할 수 없음 | UNRESOLVED | 추측으로 보완하지 않음 |

추가 원칙
- '혹평', '흥행', '정책' 같은 단어 하나만으로 판정하지 않고 제공된 문맥을 확인한다.
- 콘텐츠 정책 기사는 정치 섹션이라는 이유로 제외하지 않는다.
- 방송사명(YTN·SBS 등)이 있다는 이유로 일반 정치·사회 기사를 콘텐츠 기사로 포함하지 않는다.
  반대로 방송사 자체(민영화·매각·편성·실적·제작)가 주제면 CONTENT다.
- 종목명만 나열된 기사(테마주·관련주 목록)는 콘텐츠 기업이 포함돼도 MARKET이다.
- 연예인 개인 사건(사고·범죄·사생활)은 작품·활동 정보가 없으면 OTHER다.

## 5. 입력 조건

- 1차 검토는 **분석 모델이 실제로 받는 제목·요약만** 사용한다. 추가 검색·기억 속 외부 사실로 보완하지 않는다.
- 원문을 추가로 확인한 판단은 연구자 검토 필드(researcher_review)에 따로 기록해 정보 조건 차이를 드러낸다.
- 입력에는 기존 E2 판정·앵커·탐침 여부·추출 사유를 넣지 않는다.

## 6. 버전 관리

- 모델이 통과할 때까지 가이드를 바꾸지 않는다. 변경이 필요하면 guide_version을 올리고 변경 사유를 결정 기록에 남긴다.
- 보관 비교용 표본(holdout)을 본 뒤 규칙을 다시 조정하면, 그 표본은 이후 개발자료로 취급한다.
