# 콘텐츠산업 뉴스 Trend Radar — 구현

설계(목적·원칙)는 [TREND_RADAR_DESIGN.md](TREND_RADAR_DESIGN.md). 이 문서는 **설계의 각 장이 코드에서 어떻게 계산되는지**와
실제 원자료(2024-01 ~ 2026-09-26)에 돌려 보며 정한 것들을 적는다.

---

## 1. 실행

```bash
pip install -r requirements.txt
# 원자료(xlsx/csv/parquet)를 data/raw/에 두거나 --input으로 지정
python -m trend_radar run                       # → out/radar.html, out/tables/, out/review/
python -m trend_radar run --input "경로/*.xlsx" --out out
python -m trend_radar html --out out            # radar.json에서 화면만 다시 생성

# 규칙 후보를 따로 시험할 때 (승인 전 비교용)
python -m trend_radar run --config 다른설정.yaml --lexicon 다른규칙.yaml --out out_preview
```

형태소 분석(Kiwi)은 `out/cache/`에 캐시한다. lexicon.yaml만 바꿔 다시 돌리면 형태소 분석을 건너뛴다.
88,131건 기준 전체 실행 약 4~5분 (형태소 분석 포함 시 +1분).

## 3. 기사 정제 (3장)

원자료는 `기업 × 검색구분(주가/공시)` 행이다. 151,114행 → 전역기사ID 99,215건.

1. **기업명 실제 등장 확인** (기본 켬). 검색어가 다른 뜻으로 걸린 행을 뺀다.
   앞 글자가 한글·영숫자면 등장으로 보지 않는다 (`삼천포대교` ≠ `대교`). 별칭은 `cleaning.company_aliases`.
   실제 데이터: 151,114행 중 135,296행 남음 → **88,131건**. 등장률이 낮은 기업: 에프소드컴퍼니 0%, NEW 13%, YG PLUS 18%, 이퓨쳐 21% …
   (`out/review/lexicon_candidates.xlsx`의 '기업 등장률' 시트)
2. **반복 문형 제거** (기본 켬, `boilerplate_min_articles: 20`). 요약을 `...`·문장 끝·`|`·`▶`로 자른 조각에서
   숫자를 0으로, 기업명을 @로 가린 형태가 20개 이상 기사에 나오면 분석 텍스트에서 뺀다.
   언론사 안내문("비리와 부당대우…제보", "인용 시 [YTN …] 명시"), 자동 생성 시세 기사 문형
   ("|중앙이코노미뉴스 ○○○ 기자|출처=네이버페이 증권 …"), 종목명 나열이 여기서 빠진다. 원문 요약은 `summary_raw`로 남는다.
3. **제목 머리말 태그 제외** (`exclude_title_tags`, 사용자 승인분만). `[서울데이터랩]`, `[리스트]`, `[게임스톡]`처럼 시세·종목 나열만
   전달하는 정형 기사 36종 (2026-09-28 승인). 원인·사업 내용을 설명하는 `[특징주]`·`[더벨]` 등은 남긴다.
4. **분석 단위**. 전체 = 전역기사ID 1회. 분야 = 전역기사ID + 분야 1회 (`분야목록`의 `·` `,` `|`를 모두 구분자로 봄, 11개 분야).
   기업 = 전역기사ID + 기업 (분야 간 교차 기사 계산과 '기업 한정' 판정에 씀).

## 4. 키워드 (4~5장)

- 분석 텍스트 = 제목 + 요약. 검색어는 넣지 않는다.
- Kiwi 품사 NNG·NNP·SL(외국어). 기업명과 별칭은 사용자 사전에 넣어 한 형태소로 잡는다 (`CJ ENM` → `CJENM`).
- `생성+형`, `디지털+화`처럼 `형`·`화` 접미사는 붙인다 (`keywords.attach_suffixes`).
- 한 글자 한글 명사는 뺀다. 단, 복합어로 승인되면(`숏+폼`) 합쳐서 남는다. 병합은 형태소 캐시의 위치 정보로 하므로
  **붙어 있을 때만**(사이에 공백 없이, 또는 `-`·`·`) 합친다.
- 로마자 대소문자는 가장 많이 쓰인 표기로 통일.
- 전체 기간 10건 미만 키워드는 어휘에서 뺀다 (`min_df`).

### 후보 제안 (자동 적용 안 함)

| 후보 | 근거 지표 | 제안 |
|---|---|---|
| 불용어 | 기사 수·비중, 분야 분포 균등도(엔트로피), 분기 비중 변동계수, 최대 분야 집중도, 중심성, 기사 예시 | 제거 후보 / 검토 필요 / 유지 권고 |
| 동의어 | 괄호 병기(`인공지능(AI)`) 횟수, 가운데 글자가 빠진 줄임(`영업익`), 알려진 표기 쌍, **맥락 유사도**(연관어 벡터 코사인) | 통합 후보 / 검토 필요 |
| 복합어 | 붙어 나온 횟수, 앞·뒤 형태소 중 이 조합으로 나온 비율 | 결합 후보 / 검토 필요 |

설계 4장에 따라 주가·공시·투자·실적·정책·기술 유형은 '제거 후보'로 내지 않는다.

## 5. 지표 (6장)

키워드마다 등장 기사 수, 전체 대비 비중, 총 출현 횟수, 최초·최근 등장일, 월·분기·연 기사 수와 **비중**,
전기 대비·전년 동기 대비 (최근 분기, 비중과 기사 수 둘 다).

실제 데이터는 월 기사 수가 2024년 1~2천 건에서 2026년 3~6천 건으로 늘었다.
그래서 **모든 증가 판정은 비중 기준**이다. 절대 수만 보면 거의 모든 키워드가 증가한다.

## 6. 네트워크·군집·거리 (7~9장)

- 구간별로 기사 수 상위 400개 키워드 (`network.top_n`). 엣지 = 5건 이상 동시등장 + PMI > 0.
- 엣지 지표: 동시등장 기사 수, Jaccard, PMI, NPMI, 코사인.
- 허브 편향을 줄이려고 노드마다 Jaccard 상위 15개 엣지만 남긴다 (`max_edges_per_node`).
- Louvain (가중치 Jaccard, seed 42). 3개 미만 군집은 버린다. **군집 이름은 중심 키워드 3개로 만든 후보**일 뿐이다.
- 중심성: 연결 정도, 가중 연결 강도, 매개중심성(표본 200).
- 거리 = 1 − 코사인, 기사×키워드 이진 행렬에서 계산 (화면 배치와 무관).
- 연관어 TOP N: 코사인 순, 단 **우연 기대치의 1.2배 이상 함께 나온 단어만** (어디에나 나오는 단어 제외).

## 7. 상태 분류 (10, 13, 14장)

기간: 최근 = 마지막 2분기, 직전 = 그 앞 4분기. 연 비교는 최근 12개월 / 그 앞 12개월 / 첫 12개월.
비율은 `(기사+1)/전체` 로 평활한 비중 비율.

| 상태 | 조건 (기본값, `trend_radar.yaml`의 `status`) |
|---|---|
| Emerging | 최근 20건 이상, 직전 비중 ≤ 0.3%, 비율 ≥ 2.5배, **급증 월을 빼도** 2.5배 |
| Growing | 비율 ≥ 1.3배(급증 월 빼고도), 최근 30건 이상, 직전 20건 이상, 최근 6분기 비중 순위상관 ≥ 0.6 |
| Established | 분기 평균 비중 ≥ 1%, 변동계수 ≤ 0.4, 90% 이상 분기에 등장 |
| Spreading | 유의미 분야 수가 첫 12개월보다 2개 이상 늘고 최근 3개 이상, 비중 비율 ≥ 1 |
| Converging | 첫 12개월에도 30건 이상, 이전엔 다른 군집(또는 네트워크 밖)이던 키워드 3개 이상과 코사인이 0.03 이상 커짐, 비율 ≥ 1 |
| Declining | 비율 ≤ 0.6, 순위상관 ≤ −0.6, 직전 30건 이상, **네트워크 연결 수도 감소** |
| Event-driven | 월 비중이 평소(급증 ±1개월 제외 평균)의 4배 이상, 15건 이상, 전후 3개월 기사의 50% 이상이 그 달, 이후 2~4개월 평균이 평소 2배 미만으로 복귀(마지막 2개월 급증은 '진행 중') |

- 급증 하나로만 설명되는 증가는 Growing/Emerging이 아니라 Event-driven으로만 남는다.
- **기업 한정**: 최근 구간 기사 중 한 기업 검색에서 온 비율 ≥ 60%. 상태와 별도 표시이며 '산업 전체' 목록에서는 뺀다.
- 증가 지속기간: 3개월 이동평균 비중이 3개월 전보다 줄지 않은(5% 허용) 최근 연속 개월 수.

## 8. 분야 (11~12장)

- **유의미 등장**: 분야 기사 5건 이상 그리고 분야 기사 대비 0.3% 이상.
- **분야 확산도** = 유의미 분야 수 / 11. 반기별로 처음 유의미해진 순서가 확산 경로.
- 분야별 변화 기호: 최근 12개월 vs 직전 12개월 분야 내 비중 (↑↑ 2배, ↑ 1.25배, ↓ 0.8배, ↓↓ 0.5배).
- **공통 트렌드**(C): 최근 12개월 3개 이상 분야에서 유의미, 2개 이상 분야에서 ↑ 이상, 기업 한정 아님.
- **융합**(D):
  - 분야 거리: 분야마다 `sqrt(분야 내 비중) × max(0, log(분야 내 비중 / 전체 비중))` 벡터 (그 분야가 과대표현하는 키워드).
    분야 소속이 기업 매핑에서 오므로 **기업명 키워드는 뺀다**. 연·반기별 코사인 거리와 그 변화.
  - 교차 기사율: 서로 다른 기업을 통해 두 분야에 함께 걸린 기사 / 두 분야 중 작은 쪽 기사 수.
  - 다리 키워드: 두 분야 모두에서 과대표현된 정도가 첫 구간보다 커진 키워드.
  - 키워드 쌍: 첫 12개월에 각각 20건 이상이면서 코사인 < 0.05였다가, 최근 12개월 코사인 ≥ 0.08 · 동시등장 10건 이상.
  - 군집 다리: 최근 네트워크에서 이웃이 3개 이상 군집에 걸친 키워드 (매개중심성 순).

## 9. 구조 변화 (15장)

첫 12개월 vs 최근 12개월. 두 구간 모두 50건 이상인 키워드에서:
연관어 TOP20 (6장 기준) 겹침 Jaccard, 연관 프로필 코사인, 새/사라진 연관어, 군집 이동(대응 군집 겹침 < 0.2), 연결 중심성 변화.
겹침 ≤ 0.35 이고 **두 구간 모두 상위 연관어 평균 코사인 ≥ 0.08**(맥락이 뚜렷함)이면 구조 변화 후보.
일반어는 원래 맥락이 흐려 겹침이 늘 낮으므로 이 조건이 없으면 목록을 채운다.

## 10. 시계열 군집 (18장)

분기마다 네트워크·군집을 다시 계산하고 직전 분기 군집과 키워드 Jaccard ≥ 0.2로 잇는다.
이어지지 않은 군집은 '새 군집', 현재 대응이 없는 이전 군집은 '사라진 군집'.

## 11. 트렌드 프로파일·근거·기사 (16, 19, 20장)

종합점수는 없다. 화면의 정렬 기준(비중·증가 배율·분야 확산·지속기간·기사 수)은 사용자가 고른다.
프로파일마다 지표, 상태(복수), 근거 문장, 월별 비중, 분야별 비중·변화, 연관어 변화, 군집, 기사를 싣는다.

- 대표 기사: 최근 12개월 중 **최근 연관어를 많이 포함한** 기사
- 최근 기사, 급증 시점 기사(Event), 군집 대표 기사(군집 키워드를 많이 포함한 기사)

## 12. 실제 데이터에서 확인한 것 (1차 실행)

- **시세·공시 기사 비중이 크다.** 검색어가 `회사명+주가/공시`라서 상위 어휘가 주가·공시·대비·상승·거래… 순이다.
  이 비중 자체가 2025~26년 코스피 급등기에 커져서, 시세 어휘가 '확산'처럼 보인다.
  → 반복 문형 제거(기본), 시세 태그 제외·시세 서술어 불용어(제안)로 다룬다.
- **기업명이 다른 뜻으로 걸리는 검색어**: NEW, YG PLUS, 대교, 에프앤가이드(금융정보업체로 인용) 등.
  에프앤가이드는 기업명은 등장하지만 대부분 "에프앤가이드에 따르면" 인용이다. 제외 여부는 사용자 판단 (`exclude_companies`).
- **기업 한정 이슈**가 부상 목록에 많다 (예: 콘텐트리중앙의 지배구조·회생 관련 인명). '기업 한정' 표시로 구분한다.
- 2026년 3분기는 9월 26일까지의 부분 분기다.
